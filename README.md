# VOID

> Meet strangers. Share moments. Leave no traces.

VOID is a privacy-first ephemeral chat platform that allows people to connect instantly through anonymous, real-time conversations.

## ✨ Features

- 🔒 Anonymous chatting
- ⚡ Real-time messaging
- 🕊️ Ephemeral conversations
- 🌍 Connect with strangers worldwide
- 📱 Clean and responsive interface
- 🚀 Fast and lightweight

## 🎯 Vision

Most social platforms focus on profiles, followers, and permanence.

VOID focuses on the conversation itself.

No history. No reputation. No pressure.

Just two strangers sharing a moment in the digital void.

## 🛠️ Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Real-time Communication: WebSockets

## 🚧 Status

VOID is currently under active development.

Features, UI, and infrastructure may change as the project evolves.
